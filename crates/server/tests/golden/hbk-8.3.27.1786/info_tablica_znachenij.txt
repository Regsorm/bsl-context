# ТаблицаЗначений (`ValueTable`)

Таблица значений предназначена для хранения значений в табличном виде. Все основные операции с таблицей производятся именно через этот объект. Он позволяет манипулировать строками таблицы значений и предоставляет доступ к коллекции колонок. Колонки могут быть различных типов (в том числе множественных).

## Методы

- Вставить (`Insert`)(Индекс: Число): `СтрокаТаблицыЗначений` - 
- ВыбратьСтроку (`ChooseRow`)(Заголовок?: Строка, НачальнаяСтрока?: СтрокаТаблицыЗначений): `СтрокаТаблицыЗначений`, `Неопределено` - 
- ВыгрузитьКолонку (`UnloadColumn`)(Колонка: Число,Строка,КолонкаТаблицыЗначений): `Массив` - 
- Добавить (`Add`)(): `СтрокаТаблицыЗначений` - 
- ЗагрузитьКолонку (`LoadColumn`)(Массив: Массив, Колонка: Число,Строка,КолонкаТаблицыЗначений) - 
- ЗаполнитьЗначения (`FillValues`)(Значение: Произвольный, Колонки?: Строка) - 
- Индекс (`IndexOf`)(Строка: СтрокаТаблицыЗначений): `Число` - 
- Итог (`Total`)(Колонка: Строка): `Число`, `Неопределено` - 
- Количество (`Count`)(): `Число` - 
- Найти (`Find`)(Значение: Произвольный, Колонки?: Строка): `СтрокаТаблицыЗначений`, `Неопределено` - 
- НайтиСтроки (`FindRows`)(ПараметрыОтбора: Структура): `Массив` - 
- Очистить (`Clear`)() - 
- Получить (`Get`)(Индекс: Число): `СтрокаТаблицыЗначений` - 
- Свернуть (`GroupBy`)(КолонкиГруппировок: Строка, КолонкиСуммирования?: Строка) - 
- Сдвинуть (`Move`)(Строка: Число,СтрокаТаблицыЗначений, Смещение: Число) - 
- Скопировать (`Copy`)(Строки?: Массив, Колонки?: Строка): `ТаблицаЗначений` - Если указаны строки и колонки, то только они будут скопированы. Если не указаны, то будет создана полная копия таблицы значений.
- Скопировать (`Copy`)(ПараметрыОтбора?: Структура, Колонки?: Строка): `ТаблицаЗначений` - Если указан отбор, то только строки из отбора будут скопированы. Если отбор не указан, то будут скопированы все строки таблицы значений. Если указаны колонки, то только эти колонки будут скопированы. Иначе, будут скопированы все колонки таблицы значений.
- СкопироватьКолонки (`CopyColumns`)(Колонки?: Строка): `ТаблицаЗначений` - 
- Сортировать (`Sort`)(Колонки: Строка, ОбъектСравнения?: СравнениеЗначений) - 
- Удалить (`Delete`)(Строка: СтрокаТаблицыЗначений) - 
- Удалить (`Delete`)(Индекс: Число) - 

## Свойства

- Индексы (`Indexes`): `ИндексыКоллекции` - Содержит коллекцию индексов таблицы значений.
- Колонки (`Columns`): `КоллекцияКолонокТаблицыЗначений` - Содержит коллекцию колонок таблицы значений.
