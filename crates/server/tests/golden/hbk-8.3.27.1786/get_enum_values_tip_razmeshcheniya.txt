Значения системного перечисления ТипРазмещенияТекстаТабличногоДокумента

- Авто (`Auto`) - Не помещающийся по ширине текст будет показан в соседних по горизонтали ячейках, если в них нет текста.
- Забивать (`Block`) - Видимая часть текста будет ограничена левой и правой границами ячейки, если при этом текст не умещается полностью, то все символы видимой части будут отображаться как "#". (Применяется для предотвращения неправильного восприятия обрезанного текста).
- Обрезать (`Cut`) - Видимая часть текста будет ограничена левой и правой границами ячейки.
- Переносить (`Wrap`) - Не помещающийся по ширине текст будет переноситься на следующие строки ячейки.
