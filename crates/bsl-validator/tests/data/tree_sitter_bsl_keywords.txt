# CORE_KEYWORDS грамматики tree-sitter-bsl 0.1.7 — машинный эталон ключевых
# слов языка BSL. По одному слову в строке, русская и английская формы.
#
# Источник: tree-sitter-bsl-0.1.7/grammars/bsl/grammar.js, массив
# CORE_KEYWORDS. Из него грамматика строит правило `reserved`, поэтому это
# именно тот список, с которым язык разбирается.
#
# Снимок лежит в репозитории, а не читается из cargo-реестра при сборке:
# путь к реестру машинно-зависим (хеш каталога), и в CI пакет может быть
# собран иначе. При обновлении tree-sitter-bsl снимок сверяется с новым
# grammar.js вручную — расхождение видно в диффе.
#
# Сверка с KEYWORDS: тест `reserved_words_cover_grammar` в
# crates/bsl-validator/src/declarations.rs. Каждое слово отсюда обязано
# присутствовать в KEYWORDS — иначе правило молча пропускает имя, которое
# платформа не примет.
